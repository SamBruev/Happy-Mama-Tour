# Happy Mama Tour

Мобильный гид для поездки **с мамой в Петербург** (3–10 августа 2026).  
Стиль — как [sam-scenes](https://github.com/SamBruev/sam-scenes): тёмный фон, золото, liquid glass, плавные анимации.

## Как устроен бюджет

Во вкладке «Бюджет» две разные цифры, не путать:

- **Итого по плану** — сумма всех строк: отель + ж/д + `budgetFixed` + траты из `days[].steps[].cost`. Считается кодом, менять её можно только правкой данных.
- **Цель** — `meta.budget` в `data.js`. Ориентир. Под итогом показывается разница «сверх цели» или «запас».

Сейчас: план 115 100 ₽ при цели 85 000 ₽ → перерасход 30 100 ₽. Чтобы сойтись, придётся резать статьи (еда 28 000, музеи 12 000, день Валаама 9 500) — либо поднять `meta.budget`.

## Что внутри

| Вкладка | Содержание |
|---------|------------|
| **План** | 8 дней по шагам: время, транспорт (поезд, каршеринг, метро…), адреса, суммы |
| **Отель** | Адрес, бронь, телефон, карта |
| **Карта** | Все ключевые точки на тёмной карте |
| **Бюджет** | Отель, билеты, музеи, еда, траты по дням |
| **Смотреть** | Чеклист мест и что взять в дорогу |

## Заполнить свои данные

Отредактируйте **`data.js`**:

- `hotel` — название, адрес, цена, номер брони
- `tickets` — номера поездов, время, стоимость
- `budgetFixed` — фиксированные траты
- `days` — расписание (уже есть черновик с 3 августа, приезд в 23:00, каршеринг)

Поля с `←` — замените на реальные значения.

## Локально

```bash
cd "Happy Mama Tour"
python3 -m http.server 8080
```

http://localhost:8080

Открывать через `http://`, а не двойным кликом по файлу: на `file://` не работает service worker.

## Обновление на телефоне

Service worker отдаёт закэшированную копию сразу, а свежую качает фоном (stale-while-revalidate).
После деплоя новой версии на открытой странице появляется плашка **«План обновился → Обновить»**.
Если её не нажать — новая версия применится при следующем открытии.
